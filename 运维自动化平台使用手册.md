# 运维自动化平台使用手册

### 自动化平台约束

- 服务规范约束

|**服务端口**|后端: **8080     **  前端: **4000**|
|---|---|
|**服务日志路径**|/opt/output/logs/\*\.log|
|**泳道环境**|新项目启动泳道环境前提要先启动 base基准环境，后续再新增泳道可不关注base基准环境|
|**job\_name\(项目命名规范\)**|deeplang\-recommend\-go\-test  \-\-\-\> 项目名称\-语言\-环境  <br>语言：go、nodejs<br>环境:   test、pre、prod|
|**dockerfile**|因各个项目的构建方式和构建内容不太一致，可自行定义Dockerfile内容，目录结构为:<br>\(部署项目前需自行调试生成好Dockerfile\)<br>your\-repo/<br>└── dockerfile/<br>├── Dockerfile\.test<br>├── Dockerfile\.pre<br>└── Dockerfile\.prod|

- 语言版本号

Go 可用版本号:     

v1\.20

v1\.23

v1\.25



Nodejs 可用版本号:

v1\.22 



### 项目创建流程接口管理

##### Test环境

1. 创建和构建接口，发布基准环境，参数解释：

    - \-u  Ldap 填写用户名和密码  [深言科技云账号汇总](https://deeplang.feishu.cn/base/LRzJbdofYaMP4KsK5hkctaBknab?table=tblb0a13iQWJWWBd&view=vewZK1buC0)

    - "environment": "test" 区分部署构建的环境，有 test、pre、prod

    - "language": "go"  部署项目的语言，例如 python、go、nodejs

    - base\_version  go镜像版本 

    - domain\_name  项目域名地址

    - dayuse  容器保留时长，泳道会使用到

    - "env": "",  发布泳道环境，基准环境可以不写

    - git\_repo\_url 代码仓库地址

    - branchname 分支名称

    - job\_name 项目名称

    - location\_path 希望通过什么 path路径访问到项目，因为线上有很多服务是共用的域名，所以用路由path 来区分服务，例如 test\.lingowhale\.com/iapi/recommend    ,iapi/deeplang  也需要在你的程序中添加上这条路由

    - "**dockerfile**":"dockerfile/lingowhale/Dockerfile\.pre",   一个代码仓库下分别包含前端与后段、前端下又包含多个项目，且每个项目的构建方式不一致，例如 frontend/dockerfile/lingowhale/Dockerfile\.pre ，若是独立的代码仓库可不填写该参数

    - "**namespace**": "lingowhale",  主要pre、prod会使用到namespace环境隔离，更新历史老项目需要关注namespace，具体可**联系运维同学**确定namespace 参数，若是新创建的项目可不填写该参数

    - "**work\_dir**": "frontend",  一个代码仓库里包含了前端、后段，需要进行区分，若是独立的代码仓库可不填写该参数

    - "**update\_image\_only**": true  针对历史项目生效，是否只更新镜像即可，不需要创建服务器资源，具体可**联系运维同学**确定update\_image\_only 参数，若是新创建的项目可不填写该参数

    - "auto\_build": true   控制是否自动构建（修改为 false 只创建项目不构建）

##### Prod

1. 创建和构建接口，发布基准环境，参数解释：

- \-u  填写用户名和密码

- job\_name 项目名称

- "environment": "test" 区分部署构建的环境，有 test、pre、prod

- "language": "go"  部署项目的语言，例如 python、go、nodejs

- git\_repo\_url 代码仓库地址

- branchname 分支名称

- base\_version  go镜像版本 

- domain\_name  项目域名地址

- location\_path 希望通过什么 path路径访问到项目，因为线上有很多服务是共用的域名，所以用路由path 来区分服务，例如 pre\-v1\.lingowhale\.com/iapi/recommend  ,/iapi/deeplang  也需要在你的程序中添加上这条路由

- "auto\_build": true   控制是否自动构建（修改为 false 只创建项目不构建）
